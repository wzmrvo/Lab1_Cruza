## Project Description

This project is a responsive personal portfolio webpage created as part of a Git and GitHub laboratory activity.

The project demonstrates the use of HTML for the webpage structure, CSS for styling and responsive design, and JavaScript for interactive features.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Project Features

- Responsive portfolio design
- Navigation menu
- Home section
- About section
- Skills section
- Projects section
- Contact form
- Dark/Light mode
- Mobile-friendly layout
- JavaScript interactivity

## Git Branches

### main

The `main` branch contains the complete version of the webpage, including:

- HTML
- CSS
- JavaScript

### no-style

The `no-style` branch contains the original HTML-only version of the webpage without CSS and JavaScript.
